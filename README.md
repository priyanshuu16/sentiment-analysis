# 🛍️ Sentiment Analysis of Amazon Product Reviews

This project predicts whether a review is **positive** or **negative** using Machine Learning and Natural Language Processing.

## 🔍 Features:
- Logistic Regression with TF-IDF
- GridSearchCV for best parameters
- 94% accuracy achieved
- Preprocessing with NLTK

## 🧪 Example:
```python
predict_sentiment("The product is really awesome and works great.") 
# ➜ Positive
